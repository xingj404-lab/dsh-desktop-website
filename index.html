macOS 安装说明（Gatekeeper）

应用未使用 Apple 开发者证书签名，macOS 会拦截首次打开。请按下面步骤移除「隔离属性」即可正常使用：

1

打开「终端」Terminal

  • 按 ⌘ Command + 空格 打开「聚焦搜索」，输入 Terminal 后按回车；
  • 或：打开「访达」Finder →「应用程序」→「实用工具」→「终端」。
2

粘贴并运行下面这条命令，然后按回车

xattr -cr "/Applications/DeepSeek Harness.app"

提示：请先确认应用已放入「应用程序」文件夹；若放在其它位置，请把命令里的路径改成实际位置。

3

再次双击「DeepSeek Harness」图标即可正常打开

命令执行后终端没有任何输出即为成功，无需其它操作。

快速开始

开始使用只需四步

下载安装后，还需要一个 DeepSeek API Key 才能调用模型。按下面步骤开通，几分钟即可开始工作。

  1. 1

    注册 DeepSeek 账号

    打开 platform.deepseek.com，用手机号或邮箱注册（也可用 Google / GitHub 登录）。

  2. 2

    创建 API Key

    登录后进入 API Keys 页面，点击「创建 API Key」，复制生成的 sk- 开头的密钥。密钥只在创建时显示一次，请立即保存好。

  3. 3

    充值余额

    进入 充值 / Billing 页面，用支付宝、微信或信用卡充值（按用量计费，需先有余额才能调用 API）。部分用户可能需先完成实名认证。

  4. 4

    在桌面应用中填入 API Key

    打开 DeepSeek Harness 桌面版，进入「模型 / Models」设置页，把 API Key 粘贴进去即可，立即生效、无需重启。

还没有 API Key？前往 DeepSeek 开放平台注册并开通。详细定价请见官方定价页。

特性

原生、开箱即用的桌面体验

dsh-desktop 是 DeepSeek Harness（dsh）的 Tauri v2 桌面外壳 —— 底层界面与 dsh web 完全一致，但打包成了双击即用的原生应用。

开箱即用

打包内置 Node.js 运行时与 dsh CLI，无需安装 Node、npm 或命令行工具。

原生窗口

Dock 图标、菜单栏、缩放（⌘/Ctrl +/−、⌘/Ctrl 0）、刷新与开发者工具。

系统托盘

关闭窗口会最小化到托盘而非退出，后端继续在后台运行。

窗口状态记忆

记住窗口大小与位置，下次启动自动恢复。

后端自愈

监视 dsh web 进程，崩溃后自动重启，稳定可靠。

本地优先

后端只绑定 127.0.0.1，不对外暴露端口，数据留在本机。

架构优势

更轻、更快，没有 Electron 的臃肿

很多桌面 AI 工具用 Electron 打包，等于每个应用都内置一整个浏览器，又大又慢。DeepSeek Harness 桌面版改用更轻量的原生技术，把省下的性能都留给你。

启动更快

双击秒开，无需等待臃肿的浏览器内核加载。

体积更小

安装包更小、下载更快，不占用大量磁盘空间。

内存更省

不额外吃内存，和编辑器、浏览器一起开也不卡。

更安全

底层技术更安全，数据始终留在你的电脑上。

同样是桌面应用，Electron 会给每个应用塞进一整个浏览器；我们改用更轻的 Tauri 技术 —— 更小、更快、更省内存，同时保留了原生窗口、系统托盘与自动更新。

常见问题

你可能想问

需要安装 Node.js 或 npm 吗？

不需要。桌面版打包内置了 Node.js 运行时与 dsh CLI，下载安装即可使用，无需额外安装任何环境。

它和网页版 dsh web 有什么区别？

底层界面完全一致。桌面版额外提供原生窗口、菜单栏、系统托盘、窗口状态记忆与后端自动重启，并免去命令行安装步骤。

支持哪些平台？

目前提供 macOS（Apple Silicon）与 Windows（x64）的安装包。Linux 用户可从源码构建，参见构建指南。

macOS 提示「无法验证开发者」怎么办？

因为应用未使用 Apple 开发者证书签名。右键点击应用 →「打开」，或在终端执行 xattr -cr "/Applications/DeepSeek Harness.app"。

应用会收集或上传我的数据吗？

不会。后端只绑定本机 127.0.0.1 回环地址，不对外暴露端口，所有数据都留在你的本机。

如何更新到新版本？

桌面版内置自动更新：菜单栏 → DeepSeek Harness →「检查更新…」，即可下载并安装最新版本。
